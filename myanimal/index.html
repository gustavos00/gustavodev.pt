myAnimal

A small ecosystem for looking after animals, designed and built on my own from end to end: a mobile app where owners keep their pets' data, a web platform where vets manage their clients, and the REST API that serves both.

Parts

Mobile app

For owners, to keep track of their animals' data and status.

React Native, Expo, TypeScript

Web platform

For vets, to manage their clients and the animals they treat.

React, TypeScript

API

A REST API with JWT authentication, with Firebase for cloud services.

Node.js, TypeScript, Firebase
