One layout per screen.

A wide monitor wants columns and a vertical one wants rows. Marmita remembers a layout for each display, and ⌃ ⌥ ⌘ → moves a window across, into the same zone.

Questions.

Is Marmita free?

Yes. It is free and open source under the MIT licence.

Why does it ask for Accessibility access?

macOS only lets an app move and resize other apps' windows through the Accessibility API, so Marmita needs that permission to do its job. It uses it for nothing else, and it never connects to the internet.

Does it work with several displays?

Yes. Each display keeps its own layout, the zones of every screen appear while you drag, and a shortcut moves the active window to the next display.

I already use Rectangle. Will they clash?

Both use Control and Option with the arrow keys by default, so keep only one of them active for those shortcuts.

Free. Yours to keep.

For now, Marmita is built from source. You need macOS 14 and Xcode 16, or the Command Line Tools with Swift 6.
