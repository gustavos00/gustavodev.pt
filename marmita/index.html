Marmita

A zone-based window manager for macOS. You define layouts with the zones you want; when you drag a window with Shift held, the zones appear on screen and the window snaps and resizes into the one you drop it on. It is a native app with no dependencies, and the source is available under the MIT licence.

Screen

Features

  • Snap by dragging, with a modifier key of your choice.
  • Keyboard shortcuts to move the active window between zones and between displays.
  • A layout editor, with presets and zones drawn on a grid.
  • One layout per display.
  • Lives in the menu bar, with no Dock icon.

Shortcuts

⌃ ⌥ ← →Previous or next zone
⌃ ⌥ 1–9Zone with that number
⌃ ⌥ ⌘ ← →Previous or next display
⇧ + dragShow the zones

Install

Requires macOS 14 and Xcode 16, or the Command Line Tools with Swift 6.

git clone https://github.com/gustavos00/marmita.git
cd marmita
./scripts/build-app.sh
open build/Marmita.app

On first launch, macOS asks for Accessibility permission, which Marmita needs to move other apps' windows.
